Creating Arrays
---------------
- An Array is an ordered collection of values
    - It is resizeable

    - It can contain different data types
        - Including another Array

    - It is a zero-indexed data structure
        - 1st element w/ at the index position of 0

    - Reference (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)


Syntax:

const <constant_name> = [];                 // An empty array
const colors = ["red", "orange", "yellow"]; // An array of strings
const lottoNums = [19, 22, 56, 12, 51];     // An array of integers
const stuff = [true, 68, "cat", null];      // Ab array of mixed elements
