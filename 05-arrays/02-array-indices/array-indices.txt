Array Indices
-------------
- An Array is a zero-based indexed data structure
    - 1st element is position at index 0
        - Every element has a corresponding index index_value
    
    - An Array index is what dictates the order
        - A specific element is accessed by placing the index value w/in the pair of "[ ]"

    - The index value of -1
        - Points to the last element of an Array

Syntax:

const selectedArrayElement = <array_name>[<index>];


- The Array property ".length"
    - Returns the size of an Array
    - Reference (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array/length)

Syntax:

const arraySize = <array_name>.length;


Example:
-------

const colors = ["red", "orange", "yellow", "green", "blue", "indigo", "violet"];

colors.length;              // Returns 7
colors[0];                  // Returns 'red'
colors[colors.length - 1];  // Returns 'violet'
colors[7];                  // Returns undefined
