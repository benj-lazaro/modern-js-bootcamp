Logical AND
-----------
- Logical operator wherein BOTH operands MUST be "true"
    - In order for the entire expression to be evaluated to "true"

        <operand> && <operand>

Example:

1 <= 4 && 'a' === 'a';              // Evaluates to true
9 > 10 &&  9 >= 9;                  // Evaluates to false
'abc'.length === 3 && 1 + 1 === 4;  // Evaluates to false
