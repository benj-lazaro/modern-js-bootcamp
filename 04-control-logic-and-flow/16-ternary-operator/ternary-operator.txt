Ternary Operator
----------------
- It is the ONLY operator in JavaScript that
    - Takes three (3) operands

    - Followed by a "?" operator
        - Then an expression to execute if the condition evaluates to true (truthy)

    - Followed by a ":" operator
        - Then an expression to execute if the condition evaluates to false (falsy)

    - Basically, turning an "if-else" statement into a single line of code
        - NOTE: ONLY works if the condition can be evaluated to "true" or "false"


    <conditional_statement> ? <truthy_expression> : <falsy_expression>;
