Double Equals
-------------
- The comparison operator that
    - Checks the equality between operands by their value, NOT by their Primitive Type

    - Coerces (converts) the values compared 
        - To the SAME Primitive Type
        - The compare the equality of their values

    - Comparison operators
        - Equality                  ==
        - NOT equal                 !=

Example:

4 == 4          // Evaluates to true

'a' == 'a'      // Evaluates to true

false == false  // Evaluates to false

0 == false      // Evaluates to true; BOTH are falsy values

7 == '7'        // Evaluates to true; coerces values to a common primitive type & compare their values
