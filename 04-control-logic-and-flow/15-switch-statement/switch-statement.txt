Switch Statement
----------------
- A conditional statement that 
    - Evaluates an expression

    - Matches the value (of the expression) against a series of "case" clauses

    - Executes the statement of the matching "case" clause
        - Unit it encounters a "break" statement

    - Otherwise, executes the statement of the "default" clause
        - When the value does NOT match to ANY of the "case" clauses

    - Reference (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/switch)

    
    switch(<conditional_statement>) {
        case <value>:
            // statement
            break;
        case <value>:
            // statement
            break;
        ...
        default:
            // statement
    }
