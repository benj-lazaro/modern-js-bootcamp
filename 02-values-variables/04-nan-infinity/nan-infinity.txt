NaN & Infinity
--------------
- NaN (Not a Number) is a special numeric value that
    - Represents something that is NOT a number

        > 0/0
        < NaN

        > 1+NaN 
        < NaN

- Infinity is a special numeric value that
    - Represents a value of infinity

        > 1/0
        < infinity

        > -1/0
        < -Infinity
