parseInt & parseFloat
---------------------
- The "parseInt()" function
    - Accepts a string as an argument value & returns an integer
        - Based on the specified radix (as an optional 2nd argument)
        - The integer value between 2 & 36 represents the radix (mathematical numeral system)

        parseInt("<string_value>", [<radix_value>]);

    - Basically, it parses a string value then converts it to an integer
        - Trailing decimal numbers or non-numeric characters are EXCLUDED

    - IMPORTANT: The string value MUST BEGIN w/ a number
        - Otherwise, it returns a NaN

    - NOTE: Leading whitespace in a string value is ignored

Example:

parseInt("24");     // Returns 24
parseInt("24.987"); // Returns 24
parseInt('21') + 1; // Returns 22

parseInt("28dayslater");            // Returns 28
parseInt("I consumed 2 burgers.");  // Returns NaN


- The "parseFloat()" function
    - Identical to the "parseInt()" function EXCEPT returns a floating point number

        parseFloat("<string_value>", [<radix_value>]);

    - Reference (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/parseFloat)

Example:

parseInt("24");     // Returns 24
parseInt("24.987"); // Returns 24.987
parseInt('21') + 1; // Returns 22

parseInt("28dayslater");            // Returns 28
parseInt("I consumed 2 burgers.");  // Returns NaN
