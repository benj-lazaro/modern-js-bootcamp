null & undefined
----------------
- The Primitive Type Null
    - It represents the "intentional" absence of any object value
        - To EXPLICITLY assign the value of nothingness
    
    - It MUST be assigned to a variable w/ NO initial value

    - It is treated as a "falsy" value for boolean operations

    - Reference (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/null)

Example:

let loggedInUser = null;  // Explicitly assigns nothing to a variable w/ NO intended initial value


- The Primitive Type Undefined 
    - It represent the idea of the "lack" of value
        - A value returned (or assigned) by JavaScript

    - A variable w/ NO initial value is IMPLICITLY assigned the value of "undefined"

    - A function returns a value of "undefined"
        - If NOT value was returned 

    - Reference (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/undefined)
