String Indices
--------------
- A string value is indexed
    - Each character has a corresponding index value (i.e. positional number)
        - Based on it's position w/in the string

    - A string index starts (w/ the value of 0) from the left (i.e. 1st character)
        - Progressing towards the right of a string value
        - Index value increments by 1 as it moves towards the last character of the string

    - To access a character from a string value using it's index
        - Chain a pair of "[ ]" right after the string value
        - Pass the character's index number
        - Returns the corresponding character
        - Otherwise, returns "undefined" w/c means NO existing character at the specified index

            <string_value>[<index>];

    - To replace an existing character on a string
        - Chain a pair of "[ ]" right after the string value
        - Pass the (to be replaced) character's index number  
        - Use the "=" operator
        - Then the new character to be assigned

            <string_value>[<index>] = "<new_character_value>";

        - IMPORTANT: A string value is IMMUTABLE
            - Replacing a character will NOT be implemented
            - It will NOT trigger an error

    - It has a property named ".length" that returns a number w/c
        - Represents the number of characters w/in a string value

            <string_value>.length;

        - NOTE: A space is considered a character in a string

Example:

"chicken";                      // chicken[0] = "c"; chicken[7] = "n"
"chicken.length";               // Returns the value of 7

"          ".length;            // Returns the value of 10

let mySong = "Surfin' USA";     // Assign string value to a variables
mySong.length;                  // Returns the value of 11
mySong[0];                      // Returns the character "S"
mySong[2];                      // Returns the character "r"
mySong[11]'                     // Returns "undefined"
mySong[0] = "D"                 // Attempt to replace the character "S" at index 0 w/ a "D"
