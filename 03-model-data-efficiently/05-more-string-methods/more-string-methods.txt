More String Methods
-------------------
- The following string methods accepts argument values that modify their behavior
    - An argument value is a value passed w/in a method's pair of "( )"

        <string_value>.<method>(<argument_value>);


- Method ".indexOf()"
    - Accepts a substring (or a character) as an argument value

        <string_value>.indexOf("<substring>");

        <string_value>.indexOf("<character>");

    - It returns the index value of a substring's position w/in a string
        - Index value starts at 0
        
        - Returns an index value of -1 
            - If the substring is NOT FOUND       

        - IMPORTANT: The substring is case-sensitive

    - If a character is passed as an argument value
        - It ONLY returns the 1st matching instance of the character w/in a string

Example:

let tvShow = "catdog";

tvShow.indexOf("cat");  // Returns the value of 0
tvShow.indexOf("dog");  // Returns the value of 3
tvShow.indexOf("pup");  // Returns the value of -1; NOT FOUND


- Method ".slice()"
    - Accepts a start index as an argument values
        - Optionally, accepts an end index as well

        <string_value>.slice(<start_index>, [<end_index>]);

    - It returns the specified slice from a string value
        - Returns an empty string if the start index points to nothing
    
        - IMPORTANT: The character at the specified end index is EXCLUDED

    - NOTE: The original string value remains unchanged

Example:

let phrase = "the last crusade";

phrase.slice(0, 5); // Returns "the l"
phrase.slice(5);    // Returns "ast crusade"; starts at index 5
phrase.slice(40)    // Returns an empty string; index 40 points to nothing


- Method ".replace()"
    - Accepts two argument values
        - 1st = existing substring
        - 2nd = replacement substring

        <string_value>.replace(<existing_substring>, <replacement_substring>);

        - IMPORTANT: Replaces the 1st occurrence of the existing substring

    - It returns a new string
        - Returns the same string is the substring to be replace is NOT found

    - NOTE: The original string value remains unchanged

Example:

let annoyingLaugh = "teehee so funny! teehee!";

annoyingLaugn.replace("teehee", "haha"); // Returns a new string "haha so funny! teehee!" in memory
annoyingLaugn.replace("hoho", "haha"); // Returns the same string; "hoho" substring is NOT FOUND
