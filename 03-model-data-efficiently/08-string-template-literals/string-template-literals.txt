String Template Literals
------------------------
- Stings that are delimited with a pair of ` ` (backticks)
    - Instead of a pair of '' (single-quotes) or "" (double-quotes)

        `${<embedded_expression>}`;

    - It offers the following features:
        - Multi-line string value
        - String interpolation w/ embedded expressions & special constructs

    - The embedded expression will be evaluated & returns the resulting string value

Example:

`I counted ${3 +4} sheep`;  // Returns "I counted 7 sheep"

let userName = 'Ziggy31';
`Welcome back, ${userName}`;            // Returns "Welcome back, Ziggy31"
`Game over ${userName.toUpperCase()}`;  // Returns "GAME OVER ZIGGY31"

let item = 'cucumber';
let price = 1.99;
let quantity = 4;
`You purchased ${quantity} ${item}, total price $${price * 4}`;  
// Returns "You purchased 4 cucumber, total price $7.96"

const minAge = 21;
let yourAge = 19;
`You must be ${minAge} or older to enter, come back in ${minAge - yourAge} years`;
// Returns "You must be 21 or older to enter, come back in 2 years"
