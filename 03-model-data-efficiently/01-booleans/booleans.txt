Booleans Intro
--------------
- The Primitive Type Boolean
    - Can ONLY have two (2) values namely "true" or "false"
    - This value can be stored in a constant or variable
    - Reference (https://developer.mozilla.org/en-US/docs/Glossary/Boolean)


- To assign a boolean value to a constant & a variable
    - Use the "=" operator

Example:

const isWaterWet = true;

let isLoggedIn = true;
let gameOver = false;
