typeof Operator
---------------
- The "typeof" operator
    - Identifies the Primitive Type of the operand's value as a string value
    
        typeof <value>;

    - Reference (https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/typeof)

Example:

typeof 'hello';     // Returns "string"
typeof 2;           // Returns "number"
typeof true;        // Returns "boolean"
typeof undefined;   // Returns "undefined"
typeof null;        // Returns "object"; a weird quirk in JavaScript
